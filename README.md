# Little Jam Band Tour

Rogue-lite text adventure: follow a jam band across the country. Screens, choices, resources.

Project context lives in:

- [`ANCHOR.MD`](./ANCHOR.MD) — invariants / fantasy / non-goals
- [`CONTEXT.MD`](./CONTEXT.MD) — current loop & glossary
- [`DECISIONS.MD`](./DECISIONS.MD) — dated ADRs

## Run

```bash
pnpm install
pnpm dev
```

## Stack

Vite + React + TypeScript + Mantine + pnpm
